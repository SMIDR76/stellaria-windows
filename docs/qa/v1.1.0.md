# QA checklist for 1.1.0

Run on a real Windows 11 desktop with the release build (`artifacts\StellariaSetup-1.1.0.exe`). Tick each line, and
note the build, the date and who tested it at the bottom.

## Build

- [ ] `scripts\build-release.ps1 -Version 1.1.0` finishes and produces the setup, the portable archive and
      `SHA256SUMS.txt`.
- [ ] CI is green on the pull request: helper tests, `npm run lint`, `npm test` (including `i18n.test.mjs` and
      `app-i18n.test.mjs`), launcher build, CodeQL.

## Install and update

- [ ] Fresh install on a PC without Stellaria: the setup language follows Windows, the theme starts, the app opens.
- [ ] Update from 1.0.0 with the setup: settings, colours and favourites are kept, the theme restarts.
- [ ] Update from 1.0.0 through the app (signed `update.json`): download, signature check, install, restart, the
      "What's new" dialog shows 1.1.0.

## Languages

- [ ] Theme settings > Appearance > Language lists Automatic and the twelve languages; picking one reloads every widget
      in that language within a second.
- [ ] Automatic follows the Windows display language (test at least English, French and one of Chinese, Japanese or
      Korean).
- [ ] Bar tooltips, dashboard (all four tabs), launcher (apps, `>` actions, `>wallpaper`, `>scheme`, `:` emojis),
      utilities, session menu, notifications, island, idle screen and toasts are translated, with no French left in
      another language.
- [ ] Dates and numbers follow the language (clock tooltip, calendar, weather days, storage sizes).
- [ ] Chinese, Japanese and Korean use a readable font everywhere; German texts fit their buttons.
- [ ] The Stellaria app: Settings and the welcome screen list the languages on their own line, every page is
      translated, the tray menu follows the app language.

## Panels and Escape

- [ ] Win+Alt+A opens the dashboard; moving the pointer away keeps it open; Esc, Win+Alt+A or a click outside close
      it.
- [ ] Hovering the top edge still opens the dashboard and it closes when the pointer leaves.
- [ ] Win+Alt+U opens the utilities; same three ways to close them.
- [ ] After a panel closes, Esc works again in other apps (for example closes a dialog in File Explorer).

## Tray

- [ ] With more than four tray icons, four show and an arrow reveals the others; the arrow collapses them again.
- [ ] Turning off "Collapse the notification area" (theme settings > Desktop) shows every icon.

## Taskbar and uninstall

- [ ] With "Replace the taskbar" on, turn it off: the taskbar comes back with its original auto-hide setting and
      maximised windows stop above it.
- [ ] Stop the theme from the app: same result.
- [ ] Uninstall: the taskbar, its auto-hide setting, the accent colour and light or dark mode are as before the
      install; no Stellaria task in Task Scheduler; Zebar no longer starts Stellaria widgets; a restart changes
      nothing.

## App

- [ ] Close the app to the tray, reopen it from the tray, from the Start menu and with a `stellaria://` link: the
      content always shows.
- [ ] With Wallpaper Engine running, the Home page previews the wallpaper on screen.

## Security and trust

- [ ] Upload the setup to VirusTotal and keep the link for the release notes.
- [ ] If Microsoft Defender flags a file, submit it at <https://www.microsoft.com/wdsi/filesubmission>.
