# Code of conduct

Stellaria follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, criticise ideas rather than people, accept that maintainers decide what is
merged, and do not harass anyone, in the repository, its discussions or anywhere the project is represented.

Report unacceptable behaviour privately to the maintainers through GitHub private vulnerability reporting (Security
tab > Report a vulnerability, and say it is a conduct report). Reports are read only by the maintainers and handled in
confidence. Maintainers may remove comments, lock threads or ban accounts that break this code, following the
enforcement guidelines of the Contributor Covenant.
